# NTH-Network-Hacking-Toolkit
NTH (Network Hacking Toolkit) é uma ferramenta de linha de comando em Python com interface colorida em RGB, que reúne detalhes essenciais de pentest em um único menu: automação de SQL Injection com SQLMap, ataques de rede e MITM com Bettercap, quebra de senhas com John/Hashcat
