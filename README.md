# ⚡ NTH (Network Hacking Toolkit)

**Uma ferramenta de linha de comando em Python robusta, moderna e com interface colorida em RGB, projetada para centralizar operações essenciais de pentest em um único menu interativo.**

---

## 🎯 Sobre o Projeto

O **NTH (Network Hacking Toolkit)** foi desenvolvido para otimizar o fluxo de trabalho de profissionais de segurança da informação e pentesters autorizados. Em vez de alternar entre dezenas de ferramentas e comandos complexos, o NTH reúne as funcionalidades mais críticas de reconhecimento, exploração e pós-exploitation em um ambiente centralizado, ágil e visualmente atraente.

## ✨ Funcionalidades Principais

* 🎨 **Interface RGB Interativa:** CLI altamente customizada com cores vibrantes para melhor legibilidade e experiência visual no terminal.
* 💉 **Automação de SQL Injection:** Integração direta para varreduras e explorações rápidas utilizando o poder do **SQLMap**.
* 🌐 **Ataques de Rede & MITM:** Módulo dedicado para testes de man-in-the-middle e varreduras de rede utilizando o **Bettercap**.
* 🔑 **Quebra de Senhas (Brute-Force/Hash Cracking):** Suporte simplificado para recuperação e testes de força bruta com **John the Ripper** e **Hashcat**.
* 🧬 **Site Clone & Scan (Destaque):** Módulo completo que clona sites alvo, escaneia todos os recursos associados, gera uma réplica local estruturada e entrega um relatório detalhado do scan.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3.x
* **Bibliotecas CLI:** Rich / Colorama (para estilização e interface RGB)
* **Ferramentas Integradas:** SQLMap, Bettercap, John the Ripper, Hashcat

## 📦 Instalação

Siga os passos abaixo para configurar o NTH no seu ambiente (recomendado em sistemas baseados em Linux como Kali Linux ou Parrot OS):

```bash

# 2. Entre no diretório do projeto
cd Network-Hacking-Toolkit

# 3. Instale as dependências necessárias
pip install -r requirements.txt
